# Выгрузка в документ

Пакет без модели. Собирает из графа файл `idea.md` в папке идеи: ветки и решения, границы,
допущения, открытые вопросы, замечания проверки и журнал решений.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
